# EP50 사장님 발화 구간 · 통화 상단 순서 수정

44컷, 3×3 그리드 5장. 마지막 칸은 비워둡니다.

- S050~S100b: 상단 사장님 아이콘—통화음—안 회계사 사진, 중단 사장님 멘트, 하단 픽토그램·정리의 고정 레이아웃.
- S110~S120c: 회계사는 스튜디오 정면. 사장님 답변은 음성만 들리고 작은 아이콘·요약 자막으로 표현.
- S130 이후: 회계사 정면 설명과 자료화면 교차 편집. 전화기를 들지 않음.
- S180: 전화기 들기 제외. S210: 폴더·서류 검토나 역할 연기 제외. S220: 전체 통화 UI 대신 스튜디오 설명.
- S270: 초반 사장님 통화 포맷으로 마지막 인사 후 통화 종료.
- 정리와 클로징은 회계사 단독 스튜디오 정면 컷.

포인트 컬러 기준은 #94FC2D(RGB148,252,45)입니다. 엑셀 디자인 규칙 시트에 해당 색상 셀을 포함했습니다. 이미지 시안의 서체는 페이퍼로지 계열 고딕과 인용문 궁체 느낌이며 실제 편집 텍스트에 폰트가 임베드된 결과물은 아닙니다. 최종 편집에서는 지정 색상과 실제 서체로 조판하세요.

인물 설정은 검정 반목티·안경의 회계사, 모자 없는50대 후반~60대 초반 사장님, 흰 삼각 두건을 쓴 생기 있는 중년 아내입니다. 회계사와 부부는 대면하지 않습니다. 각 컷의 중요 요소는10%세이프존을 기준으로 구성했습니다.

금액과 세무 조건은 첨부 대본의 단순 계산 예시이며 이 작업에서 검증·확정하지 않았습니다. 이미지의 작은 글자·수치는 최종 조판 시 장면구성표와 대조하세요.

이번 수정 대상: S010, S050~S100b, S270. 상단 순서를 사장님→통화음→안 회계사로 바꿨습니다. 어두운 배경·화이트 글자·#94FC2D 포인트와 나머지 연출 규칙은 유지합니다. 3·4페이지는 변경하지 않았습니다.
