# EP48 수정 스토리보드 이미지

새로 첨부한 1.pdf의 01~24번 및 채팅 스크린샷의 25~33번 순서를 기준으로 제작했습니다.

- 본편 이미지: 31번을 제외한 32장. 모두 1920×1080 PNG, 16:9.
- 31번은 사용자의 최종 요청에 따라 제외했습니다. 번호는 재배열하지 않고 01~30, 32~33을 유지했습니다.
- 33번: 요청에 따라 채널명 없이 구독·좋아요·알림 설정만 표시했습니다.
- 12번과 22번은 각각 3장면·4장면 몽타주이며, 별도 extra_shots ZIP에 12A~12C와 22A~22D의 개별 16:9 PNG도 제공합니다.
- 11·13번의 대표 시급은 원고의 계산 근거에 맞춰 8시간 기준 약 5만 6천 원으로 통일했습니다.
- 20번 연간 표시값과 3년 합계의 반올림 차이를 명시했습니다. 3년 차이 +6,030만 원은 원고의 합계를 사용했습니다.
- 23번의 +10% 매출 지점은 +51만 원인 본전 수준으로 표시했습니다.
- 29번은 특정 실제 장소를 주장하지 않는 작은 빈 사무실의 재현 이미지입니다.
- 이 파일은 정지 이미지 묶음입니다. 원고의 동영상·모션 지시는 대표 정지 프레임으로 구성했습니다.
- 기존 잘못된 스토리보드 결과물은 보존했으며, 이번 결과는 별도 revised 폴더에만 저장했습니다.
