# EP50 전화상담 흐름·인물 일관성 수정

기준 대본: EP_1111_가족인건비_대본_전화상담형.docx

## 인물 고정 설정

- 안 회계사: 안경·검정 반목티, 크림색 벽·커튼·식물이 있는 독립된 사무실. 고객과 같은 공간에 등장하지 않습니다.
- 사장님: 50대 후반~60대 초반, 짧은 짙은 머리와 약간의 새치, 모자 없음. 실사 자료화면에서만 얼굴을 보여주고, 통화 화면은 익명 실루엣을 사용합니다.
- 아내: 생기 있는 50대 중년, 흰 삼각 두건과 앞치마. 공원 자료화면에서는 일상복·자연스러운 머리입니다.
- 글자: 일반 문구는 페이퍼로지 계열 고딕 스타일, 따옴표 인용문은 궁체 느낌. 실제 폰트가 임베드된 편집 텍스트가 아니라 생성형 이미지 시안입니다.

## 기존 오류와 수정

| 위치 | 기존 문제 | 수정 |
|---|---|---|
| S220 | 고객의 어깨 너머 회계사를 보여줘 대면 상담으로 보임 | 별도 회계사 사진과 익명 통화자 실루엣을 사용한 전화 상담 화면 |

| S310·S320 | 마무리가 일반 카드나 자료화면으로 보일 가능성 | 회계사가 직접 핵심 메시지·문의 안내·구독 인사를 말하는 단독 컷 |

## 공간·흐름 원칙

전화 상담 화면과 공방 자료화면은 구분합니다. 부부끼리 공방·공원에 함께 등장할 수 있으나 회계사와 부부가 실제로 만나는 화면은 사용하지 않습니다. 회계사의 자료 확인과 설명도 별도 사무실에서 진행합니다. 통화 종료 이후에는 ‘전화 상담 중’ 표시를 제거합니다.

44컷을 3×3 그리드 5장으로 구성하며 마지막 칸은 비워둡니다. 주요 정보는 각 컷의 10% 세이프존을 기준으로 배치합니다. 금액은 첨부 대본의 단순 계산 예시이며 이번 작업에서 실제 환급액이나 세무 적용 조건을 검증·확정하지 않았습니다. 생성 이미지의 작은 글자는 최종 편집에서 대본과 대조하여 조판하세요.
