# EP50 실사 스토리보드

원본: EP50_장면구성표_v1.xlsx

44컷을 장면 순서대로 3×3 그리드 5장으로 구성했습니다. 각 페이지는 왼쪽 위부터 가로로 읽습니다. 마지막 페이지 마지막 칸은 비워둡니다.

컷 안에는 자막·숫자·그래픽을 넣지 않은 실사 배경 시안입니다. 애니메이션 구간은 실사 소품과 상황으로 재해석했습니다. 장면 ID만 사진 아래에 표시합니다. 인물·주요 소품은 각 컷의 사방 10% 세이프존 안에 배치하도록 구성했습니다.

회계사는 최근 확정한 검정 반목티·안경의 모습, 부부는 구성표의 60대 초반 인물 설정을 기준으로 제작했습니다.

계산값과 세무 적용 조건은 이 이미지 작업에서 검증하거나 확정하지 않았습니다. 원본의 확인필요 시트를 참고하세요.
